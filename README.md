# Проект участка 6 соток

Интерактивная 3D-модель участка 600 м² у автодороги (границы по каталогу координат кадастрового плана): снятие плодородного слоя с уклоном, послойная отсыпка (щебень 40×70, щебень 20×40, песок), дренажные канавы вдоль сторон А и Б к точке 1, разрез, объёмы работ и проверки.

Страница — `index.html`, расчётная модель (геометрия, отметки, объёмы) — `model.js`, общая для 3D и чертежа. Three.js подгружается с cdn.jsdelivr.net, поэтому для 3D нужен интернет.

Чертёж (3 листа А3): `chertezh.html`, PDF — `chertezh.pdf`. Собирается из той же расчётной модели: `node gen-chertezh.js chertezh.html`.
