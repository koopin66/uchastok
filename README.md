# Проект участка 6 соток

Интерактивная 3D-модель участка 31 × 19 м у автодороги: снятие плодородного слоя с уклоном, послойная отсыпка (щебень 40×70, щебень 20×40, песок), дренажные канавы вдоль сторон А и Б к точке 1, разрез, объёмы работ и проверки.

Вся страница — один файл `index.html`. Three.js подгружается с cdn.jsdelivr.net, поэтому для 3D нужен интернет.

Чертёж (3 листа А3): `chertezh.html`, PDF — `chertezh.pdf`. Собирается из той же расчётной модели: `node gen-chertezh.js chertezh.html`.
